# 리듬 탭

떨어지는 음표가 판정선에 닿을 때 같은 줄을 톡! 4줄 리듬 게임. — [작은 오락실](https://github.com/hye-rim/smallgame) 게임

- 곡 3개: 🍡 말랑 팝(쉬움·96BPM), 🐧 달려라 펭귄(보통·128BPM), 🕹️ 밤샘 오락실(어려움·152BPM)
- 음악은 파일 없이 Web Audio로 직접 연주하고, 채보는 멜로디에 맞춰 코드로 만들어요 (같은 곡이면 언제나 같은 채보)
- 판정: PERFECT ±50ms · GREAT ±95ms · GOOD ±140ms, 10만점 만점, S~D 등급, 곡별 최고 기록 저장
- 조작: 터치(줄을 톡) / PC는 D F J K, Esc로 일시정지. 반응이 어긋나 느껴지면 메뉴의 싱크 조절(±10ms)

`index.html`을 열면 바로 실행돼요. `logic.js`에 곡 데이터·채보 생성·판정이, `game.js`에 소리·화면·입력이 있어요.
